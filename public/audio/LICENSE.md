# Original MOSAIC ambient audio

quiet-orbit.wav, ocean-current.wav and studio-air.wav were synthesized for this project from sine waves and seeded filtered noise. No recordings, commercial songs, samples or external music were used. These original audio assets are dedicated to the public domain under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/).

Each is a gentle 16-second mono loop with a quiet fade at its seam. Regenerate using the algorithm described in PHASE6.md; the audio is optional and never autoplays.
